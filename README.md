Sistema de Gerenciamento Escolar (SGE)

Um projeto de gerenciamento escolar que permite criar, ler, atualizar e deletar informações de alunos e professores (CRUD). Desenvolvido como parte do aprendizado em desenvolvimento web, com foco em front-end, back-end e deploy em nuvem.
---

🛠 Tecnologias utilizadas
Front-end: HTML (EJS), CSS, Bootstrap, JavaScript
Back-end: Node.js, Express
Banco de dados: Railway (via PostgreSQL) – OBS: os créditos acabaram, então o CRUD não está funcional atualmente
Deploy: Vercel / Railway
---

⚡ Funcionalidades
Criação/Remoção de atividades
Listagem dinâmica de dados
Entrega/Correção de atividades
Estrutura de navegação simples e responsiva
---

🚀 Como executar o projeto localmente
Clone o repositório:
git clone https://github.com/Srjuh/Projeto-Sistema_Escolar.git

Instale as dependências:
npm install

Configure o banco de dados (PostgreSQL) e ajuste as variáveis de ambiente no .env.

Execute o servidor:
npm start
Abra o navegador em http://localhost:3000.

Obs: O deploy no Vercel continua disponível apenas para visualização da interface, mas o CRUD não está ativo devido aos créditos do banco em nuvem terem acabado.
---

🔍 Aprendizados e destaques do projeto
Prática de CRUD completo integrando front-end e back-end
Estruturação de dados e manipulação dinâmica com JavaScript
Uso de templates EJS para renderização de páginas
Deploy em nuvem (Vercel/Railway) e configuração de ambiente de produção
